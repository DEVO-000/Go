# DEPLOY — DEVO+ Облако (Telegram Mini App)

Реальное облако: файлы лежат на диске сервера, метаданные — в SQLite
(Prisma). Авторизация — официальная подпись Telegram initData
(HMAC-SHA256), строгая при заданном `TELEGRAM_BOT_TOKEN`.

## 1. Запуск локально / на своём сервере (рекомендуется)

```bash
npm install            # или bun install
npx prisma db push     # создать базу (файл db/custom.db)
npm run build
npm start              # http://localhost:3000
```

Переменные окружения (файл .env):

```
DATABASE_URL=file:./db/custom.db
TELEGRAM_BOT_TOKEN=123456:ВАШ_ТОКЕН_БОТА     # строгая проверка initData
DEVO_MAX_FILE_BYTES=104857600                # лимит файла (100 МБ)
DEVO_MAX_USER_TOTAL=2147483648               # квота на человека (2 ГБ)
```

Без `TELEGRAM_BOT_TOKEN` приложение честно работает в ДЕМО-режиме
(плашка «подпись не проверяется») — удобно для быстрого просмотра.

## 2. Где хостить (честно)

- **VPS / Render / Railway (постоянный диск)** — лучший вариант: файлы и
  база живут постоянно. Нужен HTTPS-адрес (Render/Railway дают сразу).
- **Vercel** — подойдёт для ДЕМО: serverless-диск и SQLite там ЭФЕМЕРНЫ,
  загруженные файлы будут теряться. Честно учитывайте это.

## 3. Подключить к боту DEVORKS+ (одна переменная)

1. Разверните мини-апп и получите публичный HTTPS-адрес,
   например `https://devo-cloud.onrender.com`.
2. На хостинге БОТА задайте переменную окружения:

```
MINIAPP_URL=https://ваш-адрес-мини-аппа
```

3. Перезапустите бота. Появятся:
   - кнопка «🌐 Веб-облако (Mini App)» в ☁️ Облако;
   - кнопка меню бота «☁️ DEVO+» (открывает приложение).

## 4. Ограничения (честно)

- Лимит файла: 100 МБ (.env: DEVO_MAX_FILE_BYTES), квота: 2 ГБ на человека.
- Скачивание — всегда ОРИГИНАЛ байт-в-байт (никакого пережатия).
- Приложение — отдельное «веб-облако»: оно дополняет Сейф бота
  (шифрованный канал), а не заменяет его.
